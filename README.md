Student Management System


This project is a Student Management System web application that allows users to add, view, update, and delete student records efficiently. It is built using Spring Boot, Hibernate, and MySQL, following the MVC architecture.

Features
  CRUD Operations: Create, Read, Update, and Delete student records.
  
  Database Integration: Uses MySQL for storing student data.
  
  REST API: Provides endpoints for managing students.
  
  Search & Filter: Easily find students by name or ID.
  
  Responsive UI: Designed for a smooth user experience.

Technologies Used:

  Backend: Java (Spring Boot, Spring MVC, Hibernate)
  
  Frontend: Thymeleaf (for dynamic HTML rendering)
  
  Database: MySQL 
  
  Build Tool: Maven

Installation & Setup
  Clone the repository:
  
  bash
  git clone https://github.com/yourusername/student-management-system.git
  cd student-management-system
  Configure the database in application.properties:

  properties:
  
  spring.datasource.url=jdbc:mysql://localhost:3306/student_db
  spring.datasource.username=root
  spring.datasource.password=root
